# Remediation Planning Skill

Use this skill after a grounded final diagnosis identifies a problem and a
solution should be proposed.

## Boundaries

This skill does not authorize unrestricted production changes.

## Required workflow

```text
link proposed remediation to diagnosis claims and Evidence
create a remediation plan through project services
test the plan in an isolated environment
read sandbox result
apply only when project policy allows
ask the user when approval is required
```

If sandbox validation fails or policy denies the action, do not apply the
remediation.

# Architecture Diagram Sources

The `.mmd` files are the editable diagram sources. Each is rendered to a
high-resolution figure under `docs/report/figures/` and mirrored under
`docs/architecture/diagrams/rendered/` by `tools/dev/render_documentation_diagrams.py`.
Node labels use current package/class/table names; diagrams are explanatory
views, not alternate architecture.
